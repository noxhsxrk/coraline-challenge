# Product

## Register

product

## Users

Interview evaluators reviewing the code and architecture of a full-stack engineering challenge. They assess the live app on desktop Chrome and mobile Safari, looking for correctness, polish, and clean architecture.

## Product Purpose

A single-page Rock Paper Scissors game that demonstrates full-stack engineering competency: React frontend, NestJS backend, real-time WebSocket communication, Docker deployment, and test coverage. The game must be immediately playable without onboarding — scores are visible, actions are obvious, results are clear.

## Brand Personality

Minimal, clean, professional. The design serves the function — no decoration, no filler. Every element earns its place. The interface communicates reliability and attention to detail, which is what the evaluator is looking for.

## Anti-references

- Not childish or toy-like — no cartoon illustrations, no playful bouncing animations, no rainbow gradients
- Not a SaaS landing page template — no hero sections, no pricing cards, no feature grids
- Not AI-template generic — no glassmorphism, no gradient text, no side-stripe borders

## Design Principles

1. **Function first** — every visual element serves the game mechanic. Scores are immediately readable. Buttons are obvious tap targets. Bot state is unambiguous.
2. **Restraint** — minimal palette, one accent, clean typography. Nothing decorative survives review.
3. **Fast feedback** — the 2-second bot reveal, score updates, and result messages are precise and instant. No lag, no ambiguity.
4. **Works everywhere** — identical experience on desktop Chrome and mobile Safari. Touch targets ≥48px. Layout collapses gracefully.

## Accessibility & Inclusion

- WCAG AA contrast on all text
- Touch targets ≥48px for mobile play
- Reduced motion support for all animations
- Semantic HTML with ARIA labels on interactive elements
